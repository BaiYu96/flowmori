## 环境和交付

- Apple Silicon、macOS 26.6.2（25G83）、Swift 6.3.3 / Apple Command Line Tools。
- 当前收纳兼容门槛为系统构建号 25G83。其他构建自动展开并提示重新验证。

历史检查中曾出现 AppKit 虚拟窗口编号转 UInt32 溢出崩溃，现已改为验证 CG 窗口列表的几何解析并加入回归测试。此前因授权重开或更新中断的检查均不计通过。
