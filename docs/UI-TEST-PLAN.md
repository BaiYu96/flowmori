# 本机界面验收范围

电脑控制工具在解析 Flowmori 窗口时多次自身崩溃（SkyComputerUseService / Array.remove）。若使用本地辅助功能与系统事件脚本替代，限定为以下操作：

1. 读取 Flowmori 自己的窗口和控件；执行设置、历史、截图、贴图、收纳入口。
2. 创建专用测试文档，只输入固定验收文字；验证复制、中文搜索、富文本回写和截图取消。不会读取其他已有文档。
3. 通过真实系统按键路径触发 Option+V/A/P/M；验证窗口出现、焦点恢复及 Esc。
4. 启动本项目的临时菜单栏测试程序，提供普通菜单、自定义弹窗、右键菜单；将这些测试图标移入收纳区，验证点击与恢复。
5. 测试图标的启动退出和恢复；不操作用户其他应用的业务菜单。
6. 图像证据、无内容的操作日志及临时文件保存在项目 `.validation`；验收结束关闭测试程序与文档。

重新授权、系统登录注销、物理显示器插拔等动作按各自授权和实际硬件条件处理，不由此范围自动推定已完成。
