# 本机界面验收范围

电脑控制工具在解析 Flowmori 窗口时多次自身崩溃（SkyComputerUseService / Array.remove）。本地辅助功能与系统事件脚本仅限以下操作：

1. 读取 Flowmori 自己的窗口和控件；执行设置、历史、截图、贴图、收纳入口。
2. 创建专用测试文档，只输入固定验收文字；验证复制、中文搜索、富文本回写、截图取消和标注编辑。
3. 通过真实系统按键路径触发 Option+V/A/P/M；验证窗口出现、焦点恢复及 Esc。
4. 启动本项目的临时菜单栏夹具，提供普通菜单、自定义弹窗、右键状态项。验证收纳盒内直接激活：Normal/Popover 真实出现界面且图标不移出；Right 直开不可用时验证“展开菜单栏”出口，不伪造右键成功。
5. 直接激活期间用 `sampleLayout` 高频读取夹具 frame，证明没有临时移出/回流；结束后至少 4 秒保持收起。右键、源退出、超时和睡眠恢复按新交互断言，不再把“自动展开”作为所有分支的正确结果。
6. 测试真实菜单栏图标拖入：若系统没有拖放会话/来源识别，记录不可实现并报告用户，不能用面板内拖动替代。
7. 截图编辑器：在专用文档上画反向矩形、箭头、中文多行文字、单次笔划；选择/移动/删除、矩形/箭头控制点、文字重编辑；执行 Cmd+Z/Shift+Cmd+Z；验证完成复制、保存、贴图共用同一合成结果，取消不改剪贴板/历史，输出尺寸与方向正确且不含工具栏/控制点。
8. 测试图标的启动退出和恢复；不操作用户其他应用的业务菜单。
9. 图像证据、无内容操作日志和临时文件保存在项目 `.validation`；验收结束关闭夹具与测试文档。

重新授权、系统登录注销、物理显示器插拔等动作按各自授权和实际硬件条件处理，不由此范围自动推定已完成。锁屏立即停止输入，不自动解锁，不修改 TCC。用户没有外接显示器，外接屏验收保持条件不足。
